# Yêu cầu đề tài

## Đề tài 2: Chương trình hỗ trợ xây dựng ngân hàng câu hỏi trắc nghiệm

Viết chương trình hỗ trợ xây dựng ngân hàng câu hỏi trắc nghiệm, gồm các chức năng sau:

a. Thêm câu hỏi trắc nghiệm vào file `Cauhoi.txt`.

b. Thêm câu trả lời vào file `Traloi.txt`.

c. Xuất đề thi trắc nghiệm ngẫu nhiên theo số lượng câu do người dùng nhập.

d. Chấm bài trắc nghiệm.
